# Reviewer Agent

O Reviewer Agent pergunta se a mudança está correta, segura e consistente com a arquitetura. Ele investiga contratos, cenários de falha, testes ausentes, compatibilidade, segurança e efeitos indiretos.

Ele usa [[Análise por Diff]] para delimitar o escopo e [[Complexity Radar]] para decidir o nível de rigor. Sua revisão torna a explicação do [[Explainer Agent]] mais confiável, mas não substitui a decisão humana.

# Coder Agent

Responde: **como implementar?** Converte a decisão em código, testes e uma alteração revisável. Deve respeitar contratos, manter o escopo da tarefa e deixar evidências de validação para o [[Reviewer Agent]].

Uma implementação só está pronta para manutenção quando também pode ser explicada pelo [[Explainer Agent]].

# Decisões Arquiteturais

Uma decisão arquitetural merece registro quando é difícil de reverter, afeta muitos módulos ou estabelece um contrato de longo prazo. O registro preserva o contexto que o código sozinho perde.

Use [[ADR]] para decisões individuais e [[Template - Decisão Arquitetural]] ao registrar uma nova. Exemplos: fronteiras de módulos, forma de persistência, estratégia transacional, autenticação e integração assíncrona.

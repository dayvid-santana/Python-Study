# Adapter

Um adapter traduz a interface de um componente externo para o contrato que o sistema precisa. Ele existe para impedir que detalhes de SDK, protocolo ou fornecedor contaminem casos de uso.

Ao encontrá-lo no código, documente a interface interna preservada, o fornecedor adaptado e falhas de tradução. Relacionado: [[Provider]] · [[Dependências entre Camadas]].

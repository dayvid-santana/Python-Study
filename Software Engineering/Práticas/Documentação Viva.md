# Documentação Viva

Documentação viva acompanha as decisões que ainda importam para operar e evoluir o sistema. Ela não tenta espelhar cada arquivo; registra intenção, contratos, fluxos e riscos nos pontos onde o código é insuficiente como explicação.

Após uma mudança relevante, atualize a nota da mudança, os links conceituais, o [[Architecture Overview]] e ADRs afetados. Remova ou marque hipóteses obsoletas; notas contraditórias são mais perigosas que notas ausentes.

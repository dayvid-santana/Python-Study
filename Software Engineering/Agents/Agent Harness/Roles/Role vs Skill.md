# Role vs Skill

## Em uma frase

[[Role]] define **como abordar**; [[Skill]] ensina **como fazer**.

| Role | Skill |
| --- | --- |
| Define perspectiva e prioridades. | Define procedimento ou conhecimento aplicável. |
| Responde: “o que é importante aqui?” | Responde: “quais passos/técnicas uso?” |
| Pode mudar com a tarefa. | Pode ser reutilizada por vários Roles. |

## Exemplo

```text
Role: Backend Engineer

Skills:
├── Python
├── FastAPI
├── REST
├── SQL
└── pytest
```

O Role prioriza contratos, manutenção e integração de backend. A Skill de `pytest` pode ensinar convenções e comandos para escrever/executar testes.

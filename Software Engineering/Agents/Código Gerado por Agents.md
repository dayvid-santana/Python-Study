# Código Gerado por Agents

Código gerado rapidamente ainda carrega a mesma responsabilidade de código escrito manualmente: operar corretamente, evoluir com segurança e ser explicado por quem o mantém. A velocidade do agent aumenta a necessidade de rastrear intenção, não diminui.

O pacote mínimo de entrega é código, testes e [[Code Understanding Layer]]. Consulte [[Developer Comprehension]] para o critério de qualidade.
